# 🎬 AI Drama Studio

โปรแกรมช่วยทำละคร AI: พิมพ์ไอเดียเรื่อง → ได้ไบเบิลซีรีส์ (ตัวละคร, สถานที่, โครงเรื่องทุกตอน) → กดสร้างบทถ่ายทำทีละตอน
ได้ทุกช็อตพร้อม **บทพูด + พรอมต์ภาพ Start frame / End frame + พรอมต์วิดีโอ** ไปวางใน Google Flow / Veo, Kling, Runway ฯลฯ

## วิธีใช้

```bash
cd ai-drama-studio
npm install
export ANTHROPIC_API_KEY=sk-ant-...     # สมัครที่ https://console.anthropic.com
npm start
```

เปิด http://localhost:3000

## ขั้นตอนทำละครกับโปรแกรมนี้

1. **ไอเดีย** – ใส่เรื่องย่อ แนว จำนวนตอน และสไตล์ภาพ
2. **ไบเบิลซีรีส์** – คัดลอก *Character sheet* ของแต่ละตัวละครไปสร้างภาพอ้างอิงก่อน
   (ใช้ภาพนี้เป็น reference ทุกครั้ง หน้าตัวละครจะได้เหมือนกันทุกช็อต)
3. **บทถ่ายทำ** – แต่ละช็อต:
   - สร้างภาพจาก *Start frame* และ *End frame*
   - ใส่ทั้งสองภาพในโหมด Start/End (Frames to Video) แล้ววาง *Video prompt*
   - ใส่บทพูดด้วยเสียงพากย์/lip-sync
4. ตัดต่อคลิปเรียงตามเลขช็อต (1 ช็อต ≈ 8 วินาที)

ปุ่ม ⬇️ ดาวน์โหลด JSON (เปิดกลับมาทำต่อได้) และ Markdown (บททั้งเรื่อง) อยู่ใต้รายชื่อตอน
งานจะถูกจำไว้ในเบราว์เซอร์อัตโนมัติด้วย

## โครงสร้าง

```
server.js          Express + Anthropic SDK (structured JSON output)
public/index.html  หน้าเว็บ
public/app.js      แสดงผล คัดลอกพรอมต์ ส่งออกไฟล์
public/style.css   สไตล์
```

ตั้งค่าเพิ่มได้ด้วย env: `PORT` (ค่าเริ่มต้น 3000), `DRAMA_MODEL` (ค่าเริ่มต้น `claude-opus-5-5`)
ถ้าโมเดลปฏิเสธคำขอ ระบบจะลองโมเดลสำรองให้อัตโนมัติ (server-side fallback)

> โปรแกรมนี้เขียนบทและพรอมต์ ส่วนการสร้างภาพ/วิดีโอจริงทำในเครื่องมือสร้างภาพ/วิดีโอที่คุณใช้อยู่
